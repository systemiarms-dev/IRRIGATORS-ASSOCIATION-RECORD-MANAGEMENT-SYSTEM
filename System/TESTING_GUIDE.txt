SIMPLE WORDS USED HERE
  - Collection     = money coming IN (receipt)
  - Disbursement   = money going OUT (expense)
  - Prior year     = last year (used for comparison)
  - Fund balance   = total cash left
  - FS1/FS2/FS3/FS4 = the four financial report pages

TABS (left menu)
  - Overview Dashboard      (everyone)
  - Collections & Expenses  (admin, treasurer) - enter money here
  - Verification & Audit Queue (admin, auditor)
  - Financial Statements     (everyone) - generate reports here
  - User Account Manager     (admin only)
  - My Account Settings      (everyone)

HOW TO USE THIS FILE
  - Do one part at a time.
  - Type the sample data, then check the numbers on screen.
  - If screen matches the guide -> correct.
  - Mark each box with a check (/) when done.

   [ ] 2. Log ONE more expense, filling the form like this:
   EXPENSE #7 (2025-12-11):
      Type            = Disbursement
      Amount          = 2,000
      Budget Category = DISB-SUPP (or any DISB-* category)
      Payment Method  = Cash (fixed)
      Date            = 2025-12-11
      Reference / OR #= LEAVE BLANK (optional)
      Receipt Image   = none (optional)
      Notes           = LEAVE BLANK (optional)

   All the optional fields (Payer Member, Reference #, Receipt
   Image, Notes) can be left empty - the entry is still saved.

   [ ] 3. Generate a NEW 2025 statement. It must show:
      Collections = 93,500
      Expenses    = 67,500
      Net         = 26,000
      End balance = 20,000

   [ ] 4. Delete those 2 extra entries, generate again.
         Back to 23,000 and 17,000.

   PASS = the reports always use the latest data.
